# NORTE — Design System

## Direção visual

Premium, sereno, minimalista e acolhedor. A estética deve comunicar direção, clareza, natureza, constância e propósito.

## Paleta sugerida

- Navy profundo: `#0E2A45`
- Navy secundário: `#173A5B`
- Verde principal: `#2E6B57`
- Verde suave: `#DDEBE5`
- Fundo quente: `#F7F4EE`
- Card: `#FFFFFF`
- Texto primário: `#132C49`
- Texto secundário: `#6A7A8C`
- Borda: `#E5E9EC`
- Rosa família: `#F7DDE3`
- Lilás: `#E7E1F7`
- Azul suave: `#DCECF8`

## Tipografia

Usar uma sans-serif limpa e acessível. Preferência: Inter / system font.

- Título de tela: 28–34px, semibold/bold.
- Título de card: 20–24px.
- Corpo: 14–17px.
- Labels: 12–14px.

## Layout

- mobile-first;
- padding lateral 16px;
- cards com raio 18–28px;
- espaços generosos;
- sombra suave;
- botões grandes e fáceis de tocar;
- áreas de toque mínimas ~44px.

## Header

- fundo visual escuro com montanhas/amanhecer ou gradiente equivalente;
- logo NORTE no topo;
- título branco;
- frase curta/versículo opcional, editável.

## Navegação

5 itens na V1:
- Hoje
- Rotina
- Leitura
- Família
- Assistente

No protótipo atual algumas imagens antigas têm 4 itens; na implementação final usar 5.

## Logo

Símbolo de bússola/rosa dos ventos minimalista. Pode ser implementado em SVG próprio.
