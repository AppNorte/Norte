# NORTE — Fluxos do Usuário

## Primeiro uso

Splash → Começar → Onboarding → Preferências → Rotina inicial → Leitura inicial → Família → Hoje.

## Fluxo da manhã

Hoje → marcar Oração → Academia → Café → Bíblia → Livro → definir 3 prioridades → seguir o dia.

## Fluxo de leitura

Hoje/Leitura → abrir Bíblia → concluir capítulo → registrar reflexão opcional → abrir Livro → concluir meta de páginas → atualizar progresso.

## Fluxo de família

Família → escolher pessoa → registrar/planejar momento → salvar → refletir no painel semanal.

## Fluxo “O que posso fazer agora?”

Hoje/Assistente → usuário informa tempo/estado → IA consulta itens pendentes → sugere 2–5 opções com duração estimada → usuário escolhe → app abre a ação correspondente.

## Fluxo de reorganização

Usuário: “Não consegui fazer X hoje.” → IA não culpa → oferece: remarcar / manter pendente / remover → pede confirmação → atualiza.

## Fluxo noturno

Hoje/Rotina → rotina da noite → preparar roupa/água → revisar pendências → definir prioridade de amanhã → encerrar o dia.

## Conteúdo contextual

De manhã: rotina, academia, oração, leitura, prioridades.

À tarde: prioridades, pendências, agenda, família.

À noite: família, rotina noturna, fechamento e amanhã.
