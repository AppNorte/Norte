# NORTE — Critérios de Aceitação

## Geral
- funciona bem em 360–430px de largura;
- nenhuma tela exige zoom;
- navegação por 5 abas funciona;
- estado persistido após recarregar;
- sem API key no bundle do navegador.

## Hoje
- usuário consegue marcar rotina;
- editar 3 prioridades;
- ver leitura;
- abrir família;
- abrir assistente.

## Rotina
- mostrar plano progressivo;
- editar horário/ordem;
- registrar conclusão por data;
- não quebrar se usuário pular dia.

## Leitura
- plano bíblico mostra progresso;
- concluir capítulo atual;
- livro atual tem página/meta;
- registrar reflexão;
- um livro current por usuário.

## Família
- mostrar Bia, Isabella e Davi no seed;
- registrar momento;
- planejar momento futuro;
- mostrar progresso semanal leve.

## Assistente
- responde mesmo em modo mock;
- em produção usa backend;
- ações mutáveis requerem confirmação;
- falha da IA não impede usar o restante do app.
